# NovaLM-MiniLLM
NovaLM is a PyTorch language-model project demonstrating the workflow from text preparation and tokenizer training to pretraining, evaluation, and inference. It uses high-level algorithms and modern techniques, including decoder-only Transformers, grouped-query attention, RoPE, RMSNorm, SwiGLU, and experimental MoE, MLA, and MTP components.
